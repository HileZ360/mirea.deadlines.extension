Расширение для Chrome и совместимых браузеров Chromium.

## Фишки расширения, что делают кнопки

- **Обновить сроки** — один раз проверить выбранные курсы (можно добавить дисциплины вручную или сделать это автоматически). Автообновление курсов не предусмотрено, ибо избыточно.
- **Сохранить Excel** — выбрать файл при первом сохранении, сохранить в уже выбранный файл или восстановить доступ к нему.
- **Найти курсы** — внутри «Курсы и настройки» получить дисциплины текущей учётной записи и/или добавить их в список вручную.

Переключатель **Автообновление** включает и выключает периодическую проверку сроков сдачи работ.

**Изменить** рядом с именем выбранного файла позволяет выбрать другой файл Excel. Оно появляется только после выбора файла. Крестик **Свернуть окно** скрывает окно, сохраняя работу автообновления. Повторное нажатие значка расширения открывает то же окно.

Если СДО не открыто, значок открывает сайт. Если СДО уже есть в другом окне, он переводит к этой вкладке. После первого запуска на странице, открытой до установки/обновления, может потребоваться перезагрузка страницы.

## Установка и обновление

1. Распакуйте архив в постоянную папку.
2. Откройте `chrome://extensions`, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите папку `mirea_deadlines_extension`.
3. Перезагрузите страницу СДО.
4. Нажмите значок расширения, откройте «Курсы и настройки», найдите или добавьте курсы. По умолчанию выбран бакалавриат.
5. Убедитесь, что профиль СДО показывает время по Москве, и отметьте соответствующую настройку.
6. Нажмите «Обновить сроки», затем «Сохранить Excel». Выберите файл `mirea_deadlines.xlsx` на рабочем столе в папке `MireaDeadlines`.

Для обновления уже установленного расширения замените файлы в его прежней папке, нажмите кнопку обновления на карточке расширения в `chrome://extensions` и перезагрузите СДО. Если загрузите новую папку как отдельное расширение, отключите предыдущую версию.

Папку распакованного расширения следует оставить на диске.

## Сроки и сохранение

Самая давняя просрочка идёт первой, затем недавняя просрочка и предстоящие сроки от ближайшего к дальнему. Задания без подтверждённой даты находятся в конце.

## Доступ и данные

Доступ ограничен `https://online-edu.mirea.ru/`. Пароль расширение не запрашивает. Разрешение `storage` расширению не требуется.
