# Дедлайны СДО МИРЭА

<img width="1672" height="941" alt="Баннер" src="https://github.com/user-attachments/assets/81968775-6a54-4b8d-9b3b-cbb795e0dc78" />

Расширение для Chrome и совместимых браузеров на базе Chromium.

## Фишки расширения

- **Обновить сроки** — Сбор данных о дедлайнах.
- **Сохранить Excel** — Сохранение результатов в папку загрузок Вашего браузера.
- **Курсы и настройки** — Проверка добавленных курсов, выбор программы (Бакалавриат, ...) и интервала повторной перепроверки.
- **Автообновление** – вкл/выкл периодическую проверку сроков сдачи работ.

## Установка

1. Распакуйте архив там, где не предвидится его случайное удаление.
2. Откройте `chrome://extensions`, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите папку из распакованного архива.
3. Перезагрузите страницу СДО.

## Формат отображения

Самая давняя просрочка идёт первой, затем недавняя просрочка и предстоящие сроки от ближайшего к дальнему. Задания без подтверждённой даты находятся в конце.
